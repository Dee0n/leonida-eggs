# ЛЕОНИДА — коды и пасхалки GTA VI без спойлеров

Листок с пасхалками GTA VI в духе распечаток с сайтов с кодами середины 2000-х. В каждой строке
место по карте, условия и что нажать. Что там окажется, не пишем: найдёшь сам.

**Открыть листок:** https://dee0n.github.io/leonida-eggs/
**PDF для печати (A4):** https://dee0n.github.io/leonida-eggs/leonida_easter_eggs.pdf
**Нашёл пасхалку:** [прислать](https://github.com/Dee0n/leonida-eggs/issues/new?template=egg.yml)

Метки в листке:

| Метка | Значение |
|---|---|
| ● | подтверждено двумя независимыми источниками и больше |
| ○ | одно сообщение |
| ◇ | слух |

Названия мест даны по-английски, как на игровой карте. В конце каждого раздела собраны точки интереса:
туда достаточно прийти и посмотреть. Отдельный раздел посвящён неочевидным кнопкам управления. Листок пополняется по мере находок.

## Как прислать пасхалку

Проще всего через [форму](https://github.com/Dee0n/leonida-eggs/issues/new?template=egg.yml):
название, место и действие, ссылка на источник. Правила те же, что в листке:

- **без спойлеров:** место и действие, но не то, что увидишь или получишь;
- **с источником:** статья, видео, тред или свой скрин карты с меткой;
- **точное место:** «где-то на болотах» не подойдёт.

Можно и пулреквестом: правь `data/entries.json` по правилам из [AGENTS.md](AGENTS.md).

## Устройство

```
data/entries.json      — все записи, единственный источник правды
data/schema.json       — схема данных, для справки
tools/build.py         — проверка и сборка (Python 3.10+, только стандартная библиотека)
tests/test_build.py    — тесты данных и сборки
docs/                  — публичная версия для GitHub Pages (генерируется)
AGENTS.md              — правила редактирования, для людей и нейросетей
```

Формат записи:

```json
{
  "id": "unique-slug",
  "section": "keys",
  "title": "Короткое нейтральное название",
  "hint": "Где, когда и что нажать. Без описания того, что увидишь.",
  "confidence": "single",
  "sources": [{ "name": "Издание", "url": "https://..." }],
  "added": "2026-11-24",
  "added_by": "ник"
}
```

Нумерация в данных не хранится, она считается при сборке. Поэтому запись можно вставить в любое место.

## Команды

```powershell
python tools\build.py check                  # проверить данные
python tools\build.py check --strict         # то же, но предупреждения = ошибки
python tools\build.py build                  # локальная сборка в out/ (с картинками, если есть)
python tools\build.py site                   # публичная версия в docs/, без картинок
python tools\build.py new "Название" keys    # заготовка записи
python -m unittest discover -s tests -v      # тесты
```

PDF собирается через установленный Chrome или Edge. Без браузера сборка выдаст только HTML.

## Картинки

У записи может быть скрин карты: поле `image` (файл в `images/<id>.jpg`) и `image_source` (откуда он взят).
Скрины взяты из открытых гайдов (Beebom, GameSpot), под каждым стоит подпись со ссылкой на источник.
Картинка без `image_source` на сайт не попадает. Если вы правообладатель и против публикации, напишите
в issues, и мы её уберём. Свои скрины с консоли можно прислать в issue.
